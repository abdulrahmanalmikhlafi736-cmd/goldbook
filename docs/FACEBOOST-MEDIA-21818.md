## V2 changes

- Walk the selected player's single-video owning container first, up to 12 ancestors and 1,800 elements. Stop at shared/root/feed/main/article boundaries as appropriate. This avoids selecting only the beginning of a long feed.
- Sample a fixed 279-point viewport grid, at most eight hit-stack elements and six ancestors per hit, to discover visible portal rails independently of document order.
- Map fixed-label candidates to their nearest button/link/action ancestor; exclude FPRO-owned tools; deduplicate nodes. Report exact/broad Share, Copy, and lower-priority small unlabelled actions without declaring the latter to be Share.
- Export ownership categories, action ancestry, old selector/exact-label/bounds results, normalized geometry, discovery channel and ancestor-aware versus old visibility counts. Export neither labels nor action identifiers.
- New scan limits have explicit reason flags. V1 aggregate flag remains separate; its unknown cause is not reinterpreted.
- Native formatter accepts V1/V2 and rebuilds an independent numeric/geometry allowlist, caps all values and candidate count, drops unknown strings and rejects malformed/excessive payloads. Existing origin check, no automatic copy/upload and explicit native clipboard dialog remain.
- No candidate is clicked, no guessed post link or CDN URL is sent, and no poller, observer, network hook or persistent report storage is added.

Report code/limit mappings are documented in integrations/faceboost-2.18.18/README.md. Structural containment, hit testing and label categories are evidence, not proof of semantic button ownership. Finite sampling may miss controls; a zero result is not a global absence verdict.
