# البناء 28 — تحسينات محافظة من المرحلة الأولى

مرجع التطبيق السابق: `3759bcd` (البناء 27). لم ننقل محركًا جديدًا ولم نغيّر بلوك التحديد 23 أو الصوت أو سياسة CTA.

## المنفذ

- R1.1: استعلام الحوار المرئي مرة واحدة لكل دفعة layoutVideos، مع تخطي البحث إذا لم توجد فيديوهات متتبعة. `null` نتيجة نهائية «لا حوار»، وليست سببًا لإعادة البحث لكل فيديو. المعامل الافتراضي يحمي أي استدعاء مستقل لـlayout.
- R1.2: التقاط قائمة الصور مرة واحدة داخل tint وإرسالها إلى avatarCanvasPairs؛ تبقى الدالة قادرة على حساب قائمتها عند استدعائها منفردة في التشخيص. القائمة محلية للدورة فقط وليست cache دائمًا يتقادم عند تدوير DOM.
- R1.3: خريطة LIGHT_MODE_FG واحدة للمواقع الثلاثة، بالقيم السابقة نفسها دون تغيير الثيمات.
- R1.4: حذف appBanner من حلقة تصدير المفاتيح العامة، والإبقاء على التصدير الخاص ذي الافتراضي true. لم تتغير قيمة الإعداد النهائية أو تفضيلات المستخدم.
- versionCode=28؛ versionName يبقى 0.0.1 حسب طلب المالك.

## التحقق

- اختبارات DOM تعدّ الاستعلامات بالفعل: استعلام حوار واحد لدفعة فيديوهين، سواء وُجد الحوار أم لم يوجد؛ يبقى حجب أدوات الفيديو خارج الحوار واستعادتها صحيحًا.
- اختبار دورة tint واحدة مع experimentalColorVars يثبت استعلام صور واحد بدل استعلامين، حتى مع تفعيل فحص حلقات Canvas.
- اختبارات الانحدار الكاملة تتضمن تطابق التحديد مع البناء 23، الألوان والحلقات، المسار المبكر مع المفتاح العام مطفأ، حماية البحث والحساب، الوسائط والتنزيل الخارجي.
- انخفاض عدد استعلامات DOM مثبت بالاختبار؛ لا توجد هنا نسبة تسريع مقاسة لحساب Facebook فعلي.
- نتائج البناء واختبارات أجهزة Android تُضاف بعد اكتمال CI؛ نجاح اختبارات DOM وحده ليس إثبات نجاحها.

## غير منفذ عمدًا

إعادة كتابة scan، تغيير التباين/ألوان الثيمات، نقل polling إلى جسر جديد، حذف مستمع الصوت الاحتياطي، تغيير التوقيع/الهوية، تغيير حفظ حزمة Seal، أو إعادة هيكلة استعادة renderer؛ هذه ليست جزءًا من الدفعة المحافظة الحالية.
